# [Fullstack Open 2024/25] (https://fullstackopen.com/en/)

This repository includes my solutions to the exercises that I had to solve while completing the Full Stack Open course created and supported by the Department of Computer Science at the University of Helsinki and other contributors.

This course is an introduction to modern web application development with JavaScript as the base. React.js is the library that is being used the most. The main focus is building SPAs (Single Page Applications) with React that use REST APIs and Node.js.
Topics like GraphQL, testing, configuration and environment management, the use of MongoDB for storing the application's data, TypeScript as well as React Native are all part of the curriculum.

node or yarn are required.

To start an application in this repository do the following:

```bash
# Head to the desired exercise e.g. Part 1 - anecdotes
$ cd anecdotes

# Start the application
$ npm run dev

# In some cases one has to first initialize everyhting before starting the application which can be done after cding into the desired application and then using the command npm i
```
